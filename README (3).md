# Financial Automation Portfolio

Портфель кейсов по автоматизации управленческого учета, финансовой аналитики и моделирования.

## Что внутри

- реальные кейсы финансового директора;
- автоматизация учета и аналитики маркетплейсов;
- финансовая система fashion-бизнеса;
- бюджетирование и финансовый контроль EdTech;
- Finance Business Partner и консолидация данных;
- юнит-экономика стоматологии;
- налоговое и сценарное моделирование;
- автоматическая проверка контрагентов;
- валютный калькулятор.

## Главный фокус

Портфель показывает подход к автоматизации управленческого учета:
от источников данных и правил учета до ОПиУ, ДДС, управленческого баланса, контрольных проверок и управленческих решений.

Часть проектов основана на реальных кейсах, часть использует синтетические или учебные данные для демонстрации архитектуры и подхода.

## GitHub Pages

1. Создайте новый публичный репозиторий.
2. Загрузите в корень репозитория `index.html` и `README.md`.
3. Откройте `Settings -> Pages`.
4. Выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/(root)`.
6. Сохраните настройки.

Рекомендуемое имя репозитория:

`financial-automation-portfolio`
